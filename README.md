# amv-auto-data

Public data feed for the **AMVGG Adopt Me calculator**.

`data.json` is rebuilt daily by [amv-auto](https://github.com/Davidlora4535/amv-auto)
and pulled by the WordPress plugin on amvgg.net.

Do not edit by hand — the daily job overwrites this file.

| File | Contents |
| --- | --- |
| `data.json` | every pet/item with regular, neon and mega values plus price history |
| `meta.json` | last run: item count, items added, values changed |

Raw URL used by the site:

```
https://raw.githubusercontent.com/Davidlora4535/amv-auto-data/main/data.json
```
